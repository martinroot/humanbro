# Вызов агента как функции из кода сценария

Владелец задал архитектуру: предсказуемые действия запрограммированы кодом, агент вызывается ТОЛЬКО там, где нужно рассуждение, разбор неструктурированного входа или ремонт по ошибке — и проверка результата всегда остаётся кодом. Skill = инструкция агенту, не гарантия результата.

## Процедура (один шаг)
1. **Сверить сигнатуры установленной версии** перед первым вызовом в сессии: `inspect.signature(AIAgent.__init__)`, `inspect.signature(AIAgent.run_conversation)`, наличие `agent.skill_commands.build_preloaded_skills_prompt` — это внутренности, они живут на версию, а не на документацию.
2. **Предзагрузка skills до вызова модели:** `build_preloaded_skills_prompt([ids], task_id=...)` → `(prompt, loaded, missing)`; при `missing` бросать ДО обращения к модели (экономия и явная ошибка вместо шага без контекста).
3. **Создать агента ограниченно:** `AIAgent(model=..., quiet_mode=True, enabled_toolsets=[...], max_iterations=≤8, skip_memory=True, skip_context_files=True, ephemeral_system_prompt=prompt, request_overrides={"temperature": 0})` для структурированных шагов.
4. **Запуск:** `run_conversation(user_message=..., task_id=...)` → словарь, ответ по `final_response` (поддержать фолбэки `response`/`message` и строковый результат).
5. **Валидация в коде:** обязательные ключи/схема/привязка к входу проверяются Python-ом; провал → ограниченный повтор (один), в который подаётся текст ошибки парсинга.

## Pitfalls
- **Перед `sys.path.insert(0, <hermes>)` убрать из `sys.path` каталог своего скрипта:** локальные модули с именами stdlib (`queue.py` в проекте) перекрывают стандартную библиотеку, и внутренности Hermes падают на старте (`module 'queue' has no attribute 'Queue'`). Ошибка выглядит как поломка Hermes, а это коллизия имён.
- **JSON от модели считать ненадёжным даже при temperature 0:** цепочка разбора — чистка (снять fences/`json`-префикс) → первый сбалансированный `{...}` → уборка висячих запятых; при неудаче — ровно один repair-вызов с текстом ошибки, дальше провал в коде.
- **`ephemeral_system_prompt` — единственное место, куда складывается предзагруженный skill:** не полагаться, что модель сама найдёт навык через `skill_view` внутри шага.
- Бюджет шага держать конечным (`max_iterations`, `run_budget_seconds`): интеграция в цикл, который может висеть на внешнем инструменте, обязана завершаться сама.
